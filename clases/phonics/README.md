# Phonics · Blending (inglés, niños de 6 años)

Clases 1:1 de 60 minutos para pasar de reconocer sonidos a leer palabras.
Formato Gimnasio del Cerebro (skill `cca-marca`), Oki desde `assets/img/oki/`. Las sesiones 1 y 2 usan el formato
anterior (A4). Desde la sesión 3 se usa el Sistema visual Oki v2 (Carta, franja lateral, guía con plan minuto a
minuto, materiales y registro, misión para casa).

| Sesión | Tema | Fuente | PDF |
|---|---|---|---|
| 1 | Let's Make Words! Blending CVC con a e i | `s01-blending-cvc.html` | `pdf/s01-blending-cvc.pdf` |
| 2 | Vowel Detectives: CVC con las 5 vocales cortas | `s02-vocales-cvc.html` | `pdf/s02-vocales-cvc.pdf` |
| 3 | Palabras de 4 sonidos (CVCC): -st, -nd, -mp... | `s03-cvcc.html` | `pdf/s03-cvcc.pdf` |

Progresión prevista: CVC → CVCC (hand, milk) → CCVC (stop, frog) → CCVCC (stamp) → digraphs (sh, ch, th).
Cada sesión termina con un Quick Check que decide si se avanza o se repite.

Los materiales no llevan el nombre del estudiante a propósito: el repositorio es público y el sitio
se publica en gimnasiodelcerebro.co. El nombre y los resultados se escriben a mano en la hoja impresa.
Las páginas llevan `noindex`.

Regenerar los PDF:

```bash
node clases/phonics/render.js
```
