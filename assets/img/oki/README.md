# Espacio reservado para Oki

Cuando tengas los SVG oficiales de Oki, ponlos aquí con estos nombres exactos (según las 8 poses
oficiales descritas en el skill `cca-marca`) y avísame para conectarlos en el sitio:

- `oki-base-saludo.svg`
- `oki-pensando.svg`
- `oki-celebrando.svg`
- `oki-senalando.svg`
- `oki-leyendo.svg`
- `oki-ejercitando.svg`
- `oki-empatia.svg`
- `oki-sorpresa.svg`

**Regla de marca (cca-marca): nunca generar ni recrear a Oki con herramientas de IA de generación
de imagen.** Solo usar los archivos vectoriales originales. Si falta una pose, pedirla al equipo
antes de improvisar una versión nueva.

Mientras tanto, el sitio usa un ícono genérico neutro (no es Oki) en el hero de Inicio, para no
quedar sin nada mientras llegan los archivos reales.
